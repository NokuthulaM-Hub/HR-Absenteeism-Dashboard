Project Overview

This project explores HR absenteeism data using Microsoft Power BI. The dashboard provides an overview of absence days, absence incidents, planned and unplanned absences, monthly trends, leave categories, departments and employee absence patterns.

Business Objective

To demonstrate how HR data can be transformed into an interactive dashboard that helps HR teams and management monitor absenteeism and identify patterns requiring further investigation.

Tools Used

* Microsoft Excel — sample data and data preparation
* Microsoft Power BI Desktop — data modelling, DAX measures and visualisation
* GitHub — project documentation and portfolio versioning

Dashboard Features

* Total absence days
* Employees absent
* Absence incidents
* Planned versus unplanned absence days
* Monthly absence trends
* Absence days by leave category
* Absence days by department
* Site-level filtering for Gauteng, Limpopo and North West
* Employee-level absence analysis

Dataset

The project uses synthetic sample data created for learning and demonstration purposes. It does not represent actual company or employee records.

Key Learning Areas

* Building DAX measures
* Sorting month names chronologically
* Creating interactive slicers
* Designing KPI cards and charts
* Analysing HR metrics using Power BI

Disclaimer

All employee names and records in this project are fictional. The dashboard is a learning project and should not be used to make real employment decisions.
